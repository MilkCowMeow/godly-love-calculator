## 本轮确定问题与修复

### 活动归属与商品信息

旧资料链按卡牌 ID 前缀把纪事关卡分配给同卡的签到和招募活动。重建改用 Scene.Chapter 及各类原表的 ActivityID/ActivityIDs 等归属字段。相同羁绊的其他活动通过相关活动链接访问。

商品展示补入 ItemID/ItemCount 的直接奖励、Commodity.Name 中文名、Price2/PriceItemID2 与 CurrencyIDs。带分组/权重的随机奖励显示为随机候选及对应配置，避免并列奖励文字造成误读。商品与奖励原字段保持完整。

本轮修复涉及 18 个错挂关卡的签到/招募活动、75 项直发商品奖励、40 项第二币价及 41 项中文商品名。LimitCount 为负值的记录继续显示原配置值，购买次数规则留待取得对应逻辑后再作自然语言解释。

### 参数语境与强化身份

旧参数格式器无字段语境地使用统一字符串翻译表。`Who:Target` 与名为 Target 的状态 ID 碰撞，23 处条件/取值对象在 16 项技能中被显示为状态“破息”。对象选择字段现在使用对象语境的翻译，状态 ID 在引用语境中查词典。

非 Fun 成长配置此前只保存了数值，丢失属性键。现同时保留键和值，例如 `{MustCritical:1}`、`{PinchRate:0.08}`，并验证阶段详情中的身份信息。

### 原生装载后的效果详情

新增独立 `displayConfigs` 与 `displayPatches`。它们采用同一份原生声明 schema 进行投影：非法枚举使整条函数丢弃，未知字段忽略，合法枚举名称归一化。原始 `raw`、`configs` 和取证字段保留。无效函数与未被原生读取的字段从生效效果详情中移除，正文、词典与效果详情使用同一有效配置范围。

934 个发布函数对象的 Python 投影与运行时 JS 装载器交叉测试通过。定向用例额外验证非法 Target、非法 Fun、未知取值字段和未知静态属性的过滤，以及源数据保持原值。

### 原生命中字段交叉复核

此前原生注释把 `get_IsDamageHit` 读取的字段写作 AttRate。完整类型声明与两个独立调用链确认：AttRate 在 `+0x68`，Pow 在 `+0x6C`。`get_IsDamageHit` 的 `0x235E854` 实际读取 `+0x6C`，其条件为基础选择阵营 Enemy 且 Pow 非零。构造器未设置 Pow，缺省为 0。

交叉依据：`GetSkillAttRate` 在 `0x22FB958` 读取 `+0x68`；`CalculateSkillDamage` 在 `0x22FF7E8` 读取 `+0x6C`，并在 `0x22FF828` 与 AttackPowerRate 相乘。通用判定、展示范围及合成测试按 Pow 修正。当前 586 条官方技能的 Enemy 阵营数据中，AttRate 与 Pow 的非零布尔值差异为 0，现有卡牌的该项分类保持原结果。

### 事件、状态期限与冷却

NoHit 技能的原生事件生命周期、零生命变化事件及冷却修改的前后观察顺序加入定向验证。状态持续回合缩短后立即检查到期并移除对应状态。全技能冷却功能按原生主技能容器范围及主动技能标记筛选。

4 项真实缩短技能受即时到期修复影响，9 项全冷却配置采用正确技能筛选。具体证据见 [`native_event_lifecycle_20261021.md`](native_event_lifecycle_20261021.md)；新增场景使用 `tests/test_event_lifecycle.cjs` 的 8 组定向测试保护，并继续执行既有原生状态、回合、AI、连续战斗和 15 条原生伤害样本回归。
