# 2026年10月20日中文技能说明修复

## 原因

catalog_014774 的CHS、CHT文本表缺少一批旧表中存在的预置技能说明。同步脚本对缺失键返回键名，导致208项技能说明显示为 T_Skill_Description_...。先前测试检查了技能名称和富文本链接，缺少对全部说明字段的检查。

## 来源及处理

- 历史中文来源为此前保存的客户端CHS、CHT原表。
- 用014517与014774源表逐项核对描述引用和功能配置，再生成214个缺失中文键的补充记录。
- 每条补充记录均包含关联配置的SHA256指纹；读取时再次验证。配置发生变化且当前文字缺失时，停止沿用该历史文字。
- 当前有效简体中文优先，其次为当前繁体转简体；配置指纹一致时使用历史中文。
- 未找到中文的条目返回空说明，页面沿用现有缺失说明提示。
- 所有游戏链接标记统一转换为可见名称，包含双冒号格式；保留原文换行。
- 计算器、图鉴及试炼技能闭包使用一致的展示文字。
- 横幅可直接沿用已嵌入图片，文本更新无需重新编码原图。

原始字段、动态效果配置、192张卡牌的基础属性及升星数值均逐项对比，保持一致。《共奏心音》的8%治疗与4回合冷却继续采用014774配置。
