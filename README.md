## ✨ 这是什么

一个非官方的《神明恋爱放送中》资料与计算项目。将角色、技能、卡面和活动资料整理为适合阅读的图鉴，并提供按客户端配置实现的连续战斗计算器。

两个页面可以通过顶部导航互相跳转，计算在访问者自己的浏览器完成，无需登录，也无需安装程序。

### 治疗、护盾与承伤

“表格显示”可切换伤害、技能与追加伤害、状态伤害、治疗量、施加护盾或实际受伤。治疗/护盾数字可点击查看逐目标去向。治疗数字采用“有效治疗（溢出）”，治疗曲线的纵坐标为两者之和；封愈阻止另计，不加入治疗总量。有效恢复和溢出均按来源、接受者记录，持续恢复归属原始状态施加者。

成员详情可设置初始生命比例。计算后自动生成每位成员的造成伤害、实际受伤、治疗量、受到治疗量、施加护盾、获得护盾、护盾吸收及剩余生命八类折线图。支持指标筛选、角色曲线显隐、每轮/累计切换、节点数值和完整数据表；生命图保留轮末状态。全部统计数据可导出CSV，主表CSV则按当前所选指标导出。

全队快速设置支持等级、升星和行动策略。保存配队时可命名并记录当时的伤害、治疗与护盾结果，用于方案对照。定位筛选已加入选卡窗口。与参考站的完整[功能对照及验证说明](evidence/calculator_feature_comparison.md)另附。

### ⏱️ “一轮”如何定义

游戏按速度与行动条逐个角色行动。表格的一行，是从上一行结束后，汇总到所有存活队员至少各完成一次新的主行动为止。高速角色可能在同一行多动；协战、反击、持续伤害计入实际发生的行。分行不会重置状态、技能冷却或行动条。

表中的伤害为护盾后的计算伤害，保留溢出伤害；实际损血还受剩余生命与保命效果限制。战斗结束后的行不再产生伤害。

### 🎯 两种对手

- **试炼第50层**：默认保留原始双敌阵容。随从影响Boss潜影的选取条件；可关闭随从进行单Boss对照。
- **战斗人偶**：无限生命、不主动攻击或施加效果，可被附加状态；参考最大生命用于百分比技能，生命比例固定为100%。速度决定它的状态结算时点。

### 🧑‍🎨 自定义角色

点击“自定义角色”管理角色库，或在选卡窗口中“从零创建角色”。基础面板对应基准等级、0星，可独立设置每级成长和每星加成。战技与终结技支持攻击/防御/生命倍率、目标、威力、冷却、额外暴击和穿透，并可添加状态、治疗、护盾、行动条变化、净化及驱散。条件被动支持战斗开始、行动前后、技能后及受击后等触发时点。

角色保存在当前浏览器，可与原有角色混编。导出配队方案会携带所用自定义角色的完整定义，在其他设备导入即可使用；同编号但内容不同的角色会另建副本，避免覆盖本地配置。自定义角色沿用计算器已有的伤害和状态结算方式，未支持的配置仍会明确报错。

### 🎲 单场、均值与种子

- **随机单场**：真实抽样一场完整战斗。
- **多场均值**：独立维护每场战斗，再对输出取平均。小数出手次数属于跨场均值。
- **随机种子**：固定随机过程的编号；相同方案、方式、场次和种子可复现结果。

## 🚀 本地使用与开发

### 📂 直接打开

下载仓库后，用现代浏览器打开`docs/index.html`或`docs/catalog.html`即可离线使用。二者均内嵌所需资料与图片。

### 🛠️ 修改计算器

Python 3用于构建，Node.js用于运行检查；不需要安装前端框架。

```bash
python scripts/build_calculator.py
python scripts/run_tests.py
```

构建器从已发布HTML保留内嵌数据、图片和字体，再组合`src/calculator/`内的界面与模拟模块。修改字体字符集时，请同时维护对应字体资源。

```text
docs/                 🌐 GitHub Pages站点与离线HTML
src/calculator/       🧮 计算器界面与战斗解释器
src/catalog/          📖 图鉴界面源文件
scripts/              🛠️ 便携构建与检查脚本
tests/                🧪 机制与连续战斗检查
evidence/             🔬 原生核查摘要
```

### ☁️ GitHub Pages

发布源为`main`分支的`/docs`目录，包含`.nojekyll`。更新并推送后由GitHub重新部署，公开网址保持不变。
